# Tournoi International Poussins / Poussines

Site du Tournoi International Poussins / Poussines organisé par le Comité du Var de Volley-Ball : présentation, inscriptions, candidature des sélections, résultats en direct et archives.

En ligne : https://volley83.github.io/tip/

- `index.html` : le site complet (données dans Supabase).
- Les informations de l'édition à venir se modifient en haut du script, dans le bloc « ÉDITION À VENIR ».
- `dossier-tip.pdf` (facultatif) : s'il est présent, le bouton « Dossier complet (PDF) » apparaît sur la présentation.
